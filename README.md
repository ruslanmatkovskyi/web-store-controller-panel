# Online orders controller panel
That is a project that lets you control all your online orders via Terminal(i mean, not exactly directly control your online orders, but you manually add orders and their numbers in the Tool and can see all you added and more!

# Features
  - See all your orders
  - Add orders in to the app to see later all the info
  - Delete orders from the list of the app
  - Edit info of selected order

# Tech Stack
Basically, this project was made with:

Python 3.14.8
python library "time"

# Installation

So, to install this and use, you need to clone this repository

    git clone https://github.com/ruslanmatkovskyi/web-store-controller-panel.git

Go to the directory of the repository, and run file called "main.py":

    python main.py

Make Sure you have latest python installed!

# Data format

This project saves all your orders in file "orders.txt". This file have structure like this:

    ID(Tracking number), Order name, Order quantity, order price
